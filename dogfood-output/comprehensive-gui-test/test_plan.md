# CScode 全面 GUI 测试计划

## 测试目标

基于 OpenCode 架构分析和 CScode 技术规格书，对 CScode 进行全面 GUI 功能测试，重点排查：
1. 前端功能完整性
2. 并发 Session 隔离
3. 流式响应处理
4. API 端点稳定性
5. 权限系统正确性

## 测试范围

### 1. Session 管理 (核心功能)

| 测试项 | 操作步骤 | 预期结果 |
|--------|----------|----------|
| 创建新Session | 点击"New Session"按钮 | 创建新会话，自动切换到新会话 |
| 切换Session | 点击左侧会话列表中的会话 | 正确显示对应会话的消息历史 |
| 删除Session | 悬停显示删除按钮，点击确认删除 | 会话从列表中移除 |
| 重命名Session | 双击会话标题，输入新名称 | 会话标题更新 |
| 导出Session | 悬停显示导出按钮，点击 | 下载JSON文件 |

### 2. 消息交互 (LLM 对话)

| 测试项 | 操作步骤 | 预期结果 |
|--------|----------|----------|
| 发送普通消息 | 输入文本，按Enter | 显示用户消息，LLM开始响应 |
| 流式响应显示 | 发送消息后观察 | 内容逐字/逐段显示，有打字机效果 |
| 中断响应 | 点击Stop按钮 | 响应立即停止 |
| 重试响应 | 点击Retry按钮 | 重新发送最后一条用户消息 |
| 文件附件上传 | 点击附件按钮，选择文件 | 文件显示在输入框，随消息发送 |

### 3. 并发 Session 隔离 (重点)

| 测试项 | 操作步骤 | 预期结果 |
|--------|----------|----------|
| 创建多个Session | 创建Session A和Session B | 两个独立会话 |
| 并行LLM请求 | 两个Session同时发送消息 | 各自独立响应，无消息乱窜 |
| 切换查看进度 | 在响应过程中切换Session | 各Session进度独立保留 |
| 工具调用隔离 | 不同Session触发工具调用 | 工具调用不会跨Session |

### 4. 设置功能

| 测试项 | 操作步骤 | 预期结果 |
|--------|----------|----------|
| 打开设置 | 点击Settings按钮 | 显示设置对话框 |
| 切换Provider | 选择不同的Provider | 配置更新生效 |
| 切换Model | 选择不同的Model | 配置更新生效 |
| 配置API Key | 输入API Key并保存 | 配置持久化 |

### 5. 工具调用 (Tool Execution)

| 测试项 | 操作步骤 | 预期结果 |
|--------|----------|----------|
| 文件读取 | LLM调用read工具 | 正确显示文件内容 |
| 文件写入 | LLM调用write工具 | 文件正确创建 |
| Shell执行 | LLM调用bash工具 | 命令输出正确显示 |
| 网络请求 | LLM调用webfetch/websearch | 结果正确返回 |

### 6. 边界情况

| 测试项 | 操作步骤 | 预期结果 |
|--------|----------|----------|
| 网络断开 | 断开网络后发送消息 | 显示错误提示 |
| 大文件上传 | 上传超过10MB的文件 | 正确处理或显示限制提示 |
| 超长消息 | 发送超过10000字符的消息 | 正确处理或截断提示 |
| 并发上限 | 创建超过10个Session | 正确处理或显示限制 |
